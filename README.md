# Birthday Scrapbook 💌

A romantic, scrapbook-style birthday surprise made with vanilla HTML, CSS and JavaScript.

## Run it
1. Extract the ZIP.
2. Open `index.html` in your browser. For the best development experience, use VS Code with the Live Server extension.
3. Add your own photos and optional music (instructions below).

## Add your photos
Copy your pictures into `assets/photos/` and name them exactly:
- `photo1.jpg` — hero photo
- `photo2.jpg` — memory card 1
- `photo3.jpg` — memory card 2
- `photo4.jpg` — memory card 3

JPG is recommended. If your photos are PNG or WebP, either convert them to JPG or update the corresponding filenames in `index.html`.

## Add background music
Put an MP3 file at `assets/music.mp3`. Music starts only when the visitor taps the Music button, because browsers generally block autoplay.

## Personalize the message
Open `index.html` and edit:
- The birthday greeting in the hero section
- The paragraphs inside `#letterCopy`
- The reasons in the `.reason-card` elements
- The final message inside `#finalMessage`

## Publish it
You can deploy the folder to GitHub Pages, Netlify, or Vercel. If using GitHub Pages, upload the project files to a repository and enable Pages in the repository settings.
